# homebrew-tap

Homebrew formula for [ore](https://github.com/core-editor/ore), a coding agent
for the terminal.

```bash
brew install core-editor/tap/ore
```

macOS and Linux, Apple Silicon and x86_64. The formula installs the same
bundle as the standalone installer — ripgrep and the patched zsh included —
and generates shell completions.

`Formula/ore.rb` is written by ore's release pipeline; edits here are
overwritten on the next release.
